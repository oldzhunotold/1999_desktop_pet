# 1999_desktop_pet
一个用 Python + PySide6 写的《重返未来：1999》桌面宠物：透明置顶、能拖能点，
会一个字一个字地把台词说出来。

## 功能

- 透明无边框窗口，置顶显示，不占任务栏
- 13个角色、角色全服装可切换（右键菜单）
- 逐字显示的台词气泡，一段念完自动接下一段
- 点击、拖拽、自动展示都有对应动作
- 每个角色可配「初遇」「登场」台词，初遇只念一次
- 待机久了会自己挑一个动作表演（可关）
- 中文字幕、字数自适应，长句按句子切分
## 环境
- Windows 10 / 11
- Python 3.10 及以上
- PySide6  
动作名就是文件名，新增动作不用改代码
lines.txt 支持任意段数，程序会自动按宽度切成 1–2 行一段
没有 debut.txt / first_meet.txt 就不念，不会报错
自定义
改气泡速度、停留：bubble.py 顶部 CHAR_MS、HOLD_MS
改气泡宽度、行数：BUBBLE_W、MAX_LINES
改窗口大小：main_qmovie.py 的 SCALE
改菜单显示名：CHAR_LABELS、OUTFIT_LABELS
