# 1999_desktop_pet

一个用 Python + PySide6 写的《重返未来：1999》桌面宠物：透明置顶、能拖能点、会被甩出去，
还会一个字一个字地把台词说出来。

## 功能

- 透明无边框窗口，置顶显示，不占任务栏；带看门狗，资源管理器重启或休眠唤醒后自动恢复置顶
- 20 个角色、多个服装可切换（右键菜单）
- 逐字显示的台词气泡，按句子切分，一段念完自动接下一段
- 每个角色可配「初遇」「登场」台词，初遇只念一次，之后每次启动/切换念登场
- 点击、拖拽、抓握姿态、睡眠、自动表演都有对应动作
- **拖拽惯性**：快速甩出去会飞，可撞屏幕边缘反弹；重力、衰减、力度可调
- **滚轮缩放**：在桌宠上滚动滚轮即可缩放，底边固定，脚不飘
- **导入角色**：设置里可直接导入自己准备的角色素材（文件夹或 zip，支持拖拽）
- 待机久了会自己挑一个动作表演，睡一段时间会自己醒来

## 运行

```bash
python -m venv .venv
.venv\Scripts\activate
pip install PySide6
python main_qmovie.py
```

## 设置

右键 →「设置…」打开（深色界面，可拉伸缩放）。所有改动**自动保存**，没有保存按钮。

- **常规**：窗口缩放、窗口置顶、全屏时自动隐藏、光标隐藏时自动穿透、允许跨屏、允许移出屏幕、开机自启
- **桌宠**：导入角色、初始角色、初始服装
- **气泡**：打字速度、每段停留
- **动作**：自动表演间隔、自动睡觉与入睡时间、睡多久醒来、抛掷重力 / 速度衰减 / 抛掷力度
- **关于**：版本信息

设置保存在程序目录的 `settings.json`。

## 素材结构

```
assets/
└─ <角色目录>/
   ├─ <服装目录>/
   │  ├─ idle.webp       # 必需（没有时用 idle_special.webp 兜底）
   │  ├─ born.webp       # 登场动画
   │  ├─ hit.webp        # 点击
   │  ├─ sleep.webp      # 睡觉
   │  ├─ posture.webp    # 抓握姿态
   │  └─ skill1.webp ... # 其他动作，动作名即文件名
   ├─ lines.txt          # 台词，一行一段
   ├─ debut.txt          # 登场台词（可选，一行）
   ├─ first_meet.txt     # 初遇台词（可选，只念一次）
   ├─ char.json          # 显示名（可选）：{"label": "中文名"}
   └─ <服装目录>/meta.json  # 服装显示名（可选）：{"label": "服装名"}
```

- 新增动作不用改代码，文件名就是菜单里的动作名
- `lines.txt` 支持任意段数，程序按宽度自动切成 1–2 行一段
- 没有 `debut.txt` / `first_meet.txt` 就不念，不会报错

### 导入角色

设置 → 桌宠 → 「导入角色…」：

- 选择文件夹或 zip，也可以直接把文件夹/zip 拖进窗口
- 填写角色中文名，逐套填写服装中文名
- 同名角色可选覆盖（二次确认）、改名导入或取消；中文名重复会被拦下

## 打包

```powershell
python -m PyInstaller --noconfirm --windowed --onedir --name="1999桌宠" --icon="1999_desktop_pet.ico" --add-data "assets;assets" main_qmovie.py
```

打包后素材在 `_internal\assets`，程序会自动找到；`settings.json` 不入包，首次运行自动生成。

## 自定义

- 气泡速度、停留：`bubble.py` 顶部 `CHAR_MS`、`HOLD_MS`
- 气泡宽度、行数：`BUBBLE_W`、`MAX_LINES`
- 默认窗口大小：`main_qmovie.py` 的 `SCALE`
- 内置菜单显示名：`CHAR_LABELS`、`OUTFIT_LABELS`
